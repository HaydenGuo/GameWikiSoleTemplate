# 游戏站标题字样式

在 [src/config/art-typography.ts](../src/config/art-typography.ts) 的 `artTypographyStyle` 中选择全站标题字样式。当前 starter 默认使用 `playful`；新游戏站应按游戏气质选择，也可以在本地预览后调整。

| 配置值 | 适用气质 | 字形方向 |
| --- | --- | --- |
| `poster` | 工业、模拟、经营 | 厚重海报字，搭配短金色装饰线 |
| `arcade` | 复古、像素、街机 | 方正等宽字与阶梯式投影 |
| `gothic` | 黑暗奇幻、恐怖、历史奇幻 | 雕刻感衬线字 |
| `playful` | 轻松、卡通、明快 | 圆润、倾斜的展示字 |

样式会统一应用于页头站名、首页主标题、首页分段介绍标签、首页底部轮播标题和文章封面标题。页头文字颜色跟随当前主题前景色，因此亮色与深色主题都保持清晰。正文介绍和轮播说明维持常规易读字重，不使用标题艺术字。

首页必须提供 `home.hero.descriptionItems`，并且恰好包含两段，顺序固定为 `Game background` 与 `Core gameplay`。每项使用 `{ "label": "...", "text": "..." }`。原有 `home.hero.description` 继续用于页面元描述，不能替代首页分段介绍。分段标签不带底色或竖线，两段正文之间留出间距；正文应由该游戏自己的 locale 内容提供。

修改样式配置后运行 `pnpm dev` 或 `pnpm build` 即会应用。共享组件使用本仓库中的本地源码；脚本只操作标记过的标题节点和样式区块，不改游戏文案、图片或正文内容。
