# 广告接入与平台选择

> 本文说明模板广告位的启用边界、隐私要求和平台选择方法。广告网络的审核要求、可用国家/地区、流量门槛、分成、结算周期和付款方式经常调整，因此本文不维护静态门槛或收益数字。申请前请以平台官方页面和你账户内显示的规则为准。

模板内置的 AdSense 广告位由环境变量控制。相关变量见 [deployment.md 环境变量清单](deployment.md#环境变量清单)。广告变量留空时不渲染广告；先在预览环境验证，再按站点需要配置生产环境。

## 开启前先检查

- 网站已有真实、原创且维护中的内容；兑换码、价格、版本号等时效信息必须有可核对来源和最近验证记录。
- 隐私政策说明实际使用的广告和分析服务、数据用途、Cookie/追踪行为，以及用户如何管理同意或退出。
- 只使用平台允许的广告格式，并确认广告不会遮挡导航、正文或移动端操作。
- 使用同意管理组件时，按访问者所在地区和供应商文档控制脚本加载；不得绕过同意状态直接执行第三方广告脚本。
- 在桌面和移动设备检查广告加载、布局偏移、可访问性和页面性能；确认广告关闭时页面仍能正常使用。
- 不要在申请审核期间新增未经审核的广告代码或误导性跳转。

AdSense 的政策和资格由 Google 决定。不要把第三方经验、旧审计结果或某个示例站的内容数量当作过审保证。可从 [AdSense 网站获利政策](https://support.google.com/adsense/answer/48182) 和 [AdSense 付款门槛说明](https://support.google.com/adsense/answer/1709871) 查看官方要求；账户所在地、付款资料和币种会影响账户中显示的选项与数值。

## 选择广告平台

先判断平台是否接受你的内容类型、主要访客地区、流量来源和广告格式，再比较实际填报条件、分成、付款方式、隐私要求和支持质量。下面仅列出可自行核对的官方入口，不代表平台当前接受申请或承诺收入。

| 类型 | 官方入口 | 申请前需要核对 |
| --- | --- | --- |
| 通用自助广告 | [Google AdSense](https://www.google.com/adsense/start/)、[Adsterra Publishers](https://adsterra.com/publishers/)、[PropellerAds](https://propellerads.com/publishers/)、[HilltopAds](https://hilltopads.com/publishers/) | 内容政策、国家/地区支持、允许的广告格式、付款账户与结算规则 |
| 托管式广告管理 | [Journey by Mediavine](https://www.journeymv.com/)、[Monumetric](https://www.monumetric.com/publishers/) | 当前申请条件、接入方式、费用或分成、流量质量要求 |
| 游戏与娱乐垂直平台 | [NitroPay](https://nitropay.com/)、[Raptive](https://raptive.com/)、[Mediavine](https://www.mediavine.com/)、[Venatus](https://www.venatus.com/)、[Playwire](https://www.playwire.com/)、[PubNation](https://www.pubnation.com/) | 是否接受游戏 Wiki、地区构成要求、排他条款、广告体验和技术接入 |

同一平台的门槛和付款选项可能因产品、地区、流量类型或账户状态不同。不要从旧文章、论坛帖子或其他发布商的后台截图推断自己账户的条件。申请前打开平台的当前官方说明；正式接入前保存你账户实际显示的条款和配置。

## 接入 AdSense 广告位

模板通过 `PUBLIC_ADSENSE_CLIENT` 和广告位对应的环境变量启用 AdSense。保持相关变量为空即可关闭广告；只有完成供应商审核、隐私披露和广告代码配置后才填写生产值。变量名称及部署位置见 [deployment.md](deployment.md)。

模板提供 Sticky、Sidebar 和 InContent 广告位组件，分别用于页面顶部固定横幅、侧栏和文章正文区域。部署广告前，逐个检查广告位是否符合供应商政策、是否影响移动布局，以及没有填入广告配置时是否保持隐藏。广告脚本可能运行于 iframe；确认同意管理和内容安全策略配置能覆盖实际加载方式。

如果要接入其他供应商，先确认它支持静态站点和当前部署平台。不要把供应商代码直接散落到多个页面组件；集中管理加载入口，并确保广告脚本遵守 Cookie 同意状态。Adsterra 等网络的可用格式、付款方式和审核状态以 [发布商后台](https://adsterra.com/publishers/) 当前显示为准。

### 隐私与广告格式

- 面向欧洲经济区、英国及其他有同意要求的地区时，先确认适用法律和供应商文档，再决定是否允许非个性化广告在用户选择前加载。
- 在美国等采用退出机制的地区，按适用法律提供隐私告知及退出入口，并尊重浏览器或平台传递的隐私信号。
- 不启用会强制跳转、遮挡正文或模拟系统提示的格式，除非你已核实其政策兼容性并接受对阅读体验的影响。
- 若同时使用多个供应商，避免重复加载、广告位重叠和互相冲突的同意管理逻辑。
- 每次更换供应商或广告格式后，都重新检查隐私政策、内容安全策略、移动布局和真实设备表现。

## 发布前复核

1. 对照供应商当前政策确认网站、游戏内容和访客地区符合要求。
2. 核对广告脚本只在适当的同意状态下加载，并且拒绝或撤回同意后能停止非必要处理。
3. 检查广告位在桌面与移动端的位置、可关闭性、加载失败状态和页面性能。
4. 从平台后台确认站点已获准、付款资料状态正确；不要只凭脚本已出现就判断审核或付款已完成。
5. 在每次申请或平台切换前重新查看官方条款。本文不承诺申请结果、收入水平或具体到账时间。
