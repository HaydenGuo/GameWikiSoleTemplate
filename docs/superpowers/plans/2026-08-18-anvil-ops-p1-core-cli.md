# anvil-ops Core CLI Implementation Record

This archived plan records the original CLI foundation for site configuration, Search Console metrics, health checks, and evidence-backed content insights. The current supported behavior is documented in [the operations guide](../../handbook/en/ai-ops.md) and [the toolkit README](../../../tools/anvil-ops/README.md).

Current implementation uses `SITE_URL` from a local `.env` file, Google Search Console for traffic metrics, and Vercel project settings for deployment configuration. The current plan is maintained at [the Vercel migration plan](2026-10-18-template-vercel-migration.md).
