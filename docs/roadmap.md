# GameWikiSoleTemplate 路线图

> 当前正式版本以仓库 package.json 和 [GitHub Releases](https://github.com/HaydenGuo/GameWikiSoleTemplate/releases) 为准。路线图只记录当前维护基线与候选方向，不承诺发布日期或未通过评审的功能。

当前版本：**v1.1.0**。本仓库从 v1.0.0 起使用独立版本号；历史设计与决策背景见 [PRD](./PRD.md)，当前发布变更见 [CHANGELOG](../CHANGELOG.md)。

## 当前维护基线

- 保持 Astro 静态站点、单仓库源码和配置驱动的游戏身份。
- 维护首页、导航、多语言、文章内容、搜索、SEO、广告开关和模板初始化流程之间的一致性。
- 让示例内容明确区分已核实资料与布局占位内容；时效性数据必须带来源并在发布前复核。
- 让每次变更都有对应的检查结果、版本记录和可审阅的 GitHub 变更。

## 候选方向

后续工作优先处理实际维护中发现的问题。可能的改进方向包括：

- 继续减少模板示例中的游戏专属资料和过期快照。
- 提高初始化、内容校验和多语言维护之间的一致性。
- 根据真实站点反馈改进性能、可访问性和内容维护体验。

以上方向不是已承诺功能。具体实施范围以对应 GitHub Issue、PR 和正式发布记录为准。

## 当前不做的事

- 不把模板改造成托管式 SaaS。
- 不为单一游戏把专用资料、标识或运营流程写入通用运行时。
- 不把未经验证的广告门槛、收益预期、平台功能或游戏数据当作长期事实。

## 给模板使用者

模板通过 GitHub Releases 记录正式版本；升级时请先看当前版本的变更说明，再按 [上游同步指南](./staying-up-to-date.md) 操作。当前维护计划有变化时，以仓库中的 Issue 和 PR 为准。
